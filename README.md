## Speed: LiteSpeed, NVMe and AccelerateWP

WordPress is dynamic, so every uncached page makes PHP and the database do work. Caching is what keeps that work off your server.

- **LiteSpeed with LSCache** serves cached pages straight from the server, so most visitors never wait for PHP.
- **NVMe SSD storage** reads and writes faster than older SATA drives, which helps database queries and file access.
- **AccelerateWP** turns on page caching, WebP image conversion and CSS and JavaScript minification from DirectAdmin in one click, so you do not need a separate caching plugin.
- **Memcached and OPcache** are available to speed up PHP and object caching.

Multiple PHP versions are available (7.4 to 8.2 as listed), and you can edit your php.ini from the control panel.

## Security and Backups

WordPress is popular, which makes it a steady target. YouStable adds protection at the server level, so your site is not relying on a plugin alone.

- **Imunify360** scans for malware, blocks brute force login attempts and quarantines infected files.
- **Web application firewall, network firewall and Monarx** add further layers of protection.
- **CloudLinux account isolation** keeps each account separate, so a problem on another account cannot touch your site.
- **Two factor authentication** is available for your hosting account.
- **Free SSL from Let's Encrypt** installs and renews on its own for every domain.
- **Weekly backups** are stored off site, and you can restore your files, database and media from DirectAdmin in one click.

Backups run weekly, so a restore point can be up to a week old. If you publish or take orders every day, take a manual backup before big updates, or add a daily backup plugin of your own.
